时间时长做什么

周六 上午3 小时主攻作品。这是唯一写代码的整块时间，手机放远

04工具箱

全部免费或极低成本。总预算控制在 200 元以内。

学 SQL 与 Python

牛客网 SQL 篇（免费刷题）、LeetCode 数据库、Kaggle Learn 的 Pandas 微课（2 小时能过完）。不要买课，不要看长视频教程。

搭 RAG

LangChain 或 LlamaIndex 官方文档、Chroma 做向量库（本地跑，零成本）、Streamlit 做界面。

模型接口

DeepSeek（便宜，适合练手）、智谱 GLM-4-Flash（有免费额度）。做完三个作品大概花 30–60 元。

部署与展示

Streamlit Community Cloud 免费部署、GitHub 放代码。链接就是你的简历第一行。

05五条铁律

1

作品必须有链接。本地的代码文件夹在面试官眼里等于不存在。能点开、别人能用，才算作品。

2

不考证。初级会计、证券从业、期货从业对你主攻的岗位零价值。CDA 一级可考，准备别超过一周，且别指望它救场。

3

不做工具收藏家。新模型每两个月出一个，追不完。把一个 RAG 做扎实，胜过试十个工具。

4

不碰算法训练。PyTorch 调参、Spark 全家桶在你的赛道里是负收益，省下的时间全给作品和面试。

5

实习优先于绩点。保证不挂科即可。大三下能拿到实习，比绩点从 3.4 提到 3.7 重要十倍。
